# README — vfs-shell (этап 1)

## О проекте

`vfs-shell` — учебный эмулятор UNIX-подобной командной оболочки
с графическим интерфейсом на Swing. Проект создаётся поэтапно; в текущем
виде реализован **этап 1 — REPL-прототип**.

Большинство команд пока являются заглушками, но диалог с пользователем,
парсинг строки, обработка ошибок и запуск команд уже работают.


## Цель этапа 1

Создать минимальный прототип оболочки: интерактивный REPL с графическим
окном, поддержкой разбора строки, раскрытием переменных окружения и
базовым набором команд-заглушек.


## Возможности

- GUI: окно с эмуляцией терминала (`JTextArea` на чёрном фоне).
- Заголовок окна содержит имя VFS: `VFS-Shell — <путь к VFS>`.
- Парсер команд:
  - раскрытие переменных окружения реальной ОС: `$HOME`, `${HOME}`, `$USER` и т.п.;
  - токенизация с поддержкой одинарных и двойных кавычек;
  - сообщение об ошибке при незакрытой кавычке.
- **История команд** (стрелки ↑/↓).
- **Редактирование только текущей строки** — курсор не выходит за пределы приглашения.
- **Обработка ошибок**: неизвестная команда, неверные аргументы, незакрытые кавычки, исключения внутри команды.
- **Стартовый скрипт** (`--script FILE`): построчное выполнение с эхо и пропуском комментариев (`#`).
- **Автоскролл** вывода и отладочная информация при запуске (`--no-debug` для отключения).

## Поддерживаемые команды

| Команда | Назначение |
|---------|------------|
| `ls`    | заглушка — печатает имя и аргументы |
| `cd`    | заглушка — печатает имя и аргументы; ругается на >1 аргумента |
| `exit`  | завершает эмулятор (аргументы не поддерживаются) |
